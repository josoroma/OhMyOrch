# Archived Changes

One directory per delivered change, named `<yyyy-mm-dd>-<change-id>`, holding the
full artifact trail: `proposal.md`, `specs/`, `tasks.md`, `implementation-plan.md`,
`review.md`, `test-report.md`, `status.md`, and `completion.md` when present.

This directory is the durable implementation history. A resuming session can read
it to see what was decided, what was verified, and why. Do not delete an archived
change: it is the evidence behind the capability spec that replaced it.
