# Delivery Goal

The recorded delivery goal lives here as `goal.md`, written by `scripts/delivery.sh`
when `/deliver` starts. `loop.state` holds the per-machine stall counter that
`scripts/guard-delivery-loop.sh` keeps; it is machine-local and must not be
committed.

No goal is recorded in the canonical initial state, so the delivery `Stop` hook
fails open and the loop does not engage until `/deliver <target>` is run.

The next action is always derived by `scripts/delivery.sh next`. `goal.md` is a
record for a human reader and is never read back as input.
