# Delivery Records

One file per delivered epic, named `README-EPIC-<n>.md`, recording what that epic
delivered and how it was verified.

These records are explanatory, not normative. The authoritative account of a
delivered change is the change's own artifact trail under
`openspec/changes/archive/`.

Write a record when an epic reaches `DONE`: the stories delivered, the archived
changes, the review and test outcome, and anything the epic left unresolved.
