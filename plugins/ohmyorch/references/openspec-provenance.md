# OpenSpec prompt provenance

Seven source prompts were generated by OpenSpec 1.13.2 (`@fission-ai/openspec`) in the original tracked revision 6198da15df78cd5a68d4227abd4e4e5d27372ac8. Upstream: https://github.com/Fission-AI/OpenSpec.

The seven `skills/opsx-*` bodies are byte-identical to the skills OpenSpec 1.13.2 generates with the seven-workflow custom profile (propose, explore, apply, update, sync, verify, archive), apart from two local adaptations:

1. Plugin namespace. The frontmatter `name:` is `opsx-<name>`, and every upstream `/opsx:<name>` command and the `openspec-sync-specs` skill reference reads `/ohmyorch:opsx-<name>`.
2. One `## OhMyOrch boundary` paragraph directly after the frontmatter.

Regenerate only in a maintainer scratch project, with a tool selected under that profile, for example `openspec init --tools claude`. `--tools none` generates no skills. The upstream skill directories are `openspec-explore`, `openspec-propose`, `openspec-apply-change`, `openspec-verify-change`, `openspec-sync-specs`, `openspec-update-change` and `openspec-archive-change`. Compare each generated `SKILL.md` with the bundled one and reapply the two adaptations. Never run `openspec update` in consumer projects to update plugin code.
