# Canonical Capability Specs

One directory per capability, each containing a `spec.md`. These are the current
agreed behavior of the product — the state a change updates when it is archived.

A capability spec is written from archived changes, never by hand. When a change
is archived, OpenSpec applies its delta specs to the matching capability here.

```bash
openspec list
openspec validate --all --strict
```
